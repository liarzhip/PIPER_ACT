# 继续训练与追加轮次

进入模型训练页面，确认任务和模型目录后，在顶部选择训练方式：

- 从头训练：使用新模型目录，避免覆盖已有模型。
- 继续至目标总轮数：例如保存到 30 轮、目标总轮数填 100，则从第 31 轮训练到第 100 轮。
- 在已保存进度上追加轮次：例如保存到 30 轮、追加 50，则训练到第 80 轮。已完成的训练同样可以追加。

点击“开始训练”后，自动优先恢复 training_state.ckpt；没有完整断点时，使用最近带编号的 policy_epoch_*.ckpt，或有训练历史的 policy_last.ckpt，最后才回退到 policy_best.ckpt。仅有 best 权重而没有历史时，原轮次未知，从 0 计数。

旧版断点只能恢复权重，优化器重新初始化。没有历史文件的旧训练无法补回损失曲线。新版每轮结束原子保存模型、优化器、轮次、随机状态、训练历史及最佳模型。进程意外终止时，可以恢复到最后完整保存的轮次。

“完成本轮后停止”会等待本轮训练结束并保存，期间可能需要几分钟。不要直接关闭训练进程，否则本轮未保存的进度会丢失。

续训沿用原有模型结构、归一化以及已保存的训练参数。旧版没有参数历史时，未保存的参数使用界面值；数据划分或统计不一致会拒绝续训。请保持原数据不变。恢复前会在模型目录 resume_backups 下保留旧 best/last 和配置历史。

命令行示例：
```powershell
python train_piper_act_dual_rgbd_global_v7.py --dataset_dir "D:\piper_act\Dataset\任务名" --ckpt_dir "D:\piper_act\checkpoints\模型目录" --resume --additional_epochs 50
```
只继续到指定总轮数时，将 `--additional_epochs 50` 换成 `--num_epochs 100`。
