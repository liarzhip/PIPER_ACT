### 1. 执行采集数据程序
```sh
python piper_act_recorder_Linux.py

or 

python piper_act_recorder_windows_dual_rgbd_v7.py `
  --dataset-dir "D:\piper_act\Dataset\dataset_stand_bottle_dual_rgbd" `
  --fps 20 `
  --wrist-width 640 `
  --wrist-height 480 `
  --wrist-fps 30 `
  --wrist-depth-min-mm 150 `
  --wrist-depth-max-mm 1500 `
  --external-width 640 `
  --external-height 480 `
  --external-fps 30 `
  --external-depth-min-mm 250 `
  --external-depth-max-mm 3000 `
  --max-camera-sync-delta 0.05
```
顶部窗口回显示：
```sh
READY | S: start recording | Q/ESC: quit
```
可以先根据腕部相机画面调整机械臂和目标物体的位置。  

（1）按s开始记录Episode，之后窗口顶部会变成：
```shell
REC | Q/ESC: stop & save
```
（2）示教完成后按 q 或者 Esc 就会停止并且自动保存：
```shell
dataset_stand_bottle/
└── episode_000000.hdf5
```
### 2. 验证采集到的数据
（1）图像显示，按照数据集采样频率播放
```shell
python validate_act_episode.py \
    dataset_stand_bottle/episode_000000.hdf5 \
    --play
```
键盘控制：
```shell
SPACE    暂停/继续
A        暂停时上一帧
D        暂停时下一帧
Q / ESC 退出
```
（2）生成 qpos 和 action 曲线：
```shell
python validate_act_episode.py \
    dataset_stand_bottle/episode_000000.hdf5 \
    --plots
```
生成目录：
```yaml
episode_000000_validation/
├── j1_qpos_action.png
├── j2_qpos_action.png
├── j3_qpos_action.png
├── j4_qpos_action.png
├── j5_qpos_action.png
├── j6_qpos_action.png
└── gripper_qpos_action.png
```
